# Decisions and deviations from PLAN.md

| # | Date | Decision | Reason |
|---|---|---|---|
| 1 | 2026-11-22 | User-facing commands are written as **skills** (`skills/<cmd>/SKILL.md`, `disable-model-invocation: true`) instead of `commands/*.md`. Internal skills (course-context, verify-pass, figure-handling, drill-method) use `user-invocable: false`. | Current docs (code.claude.com/docs/en/plugins/components) say `commands/` is the legacy format and new commands should be skills. Invocation is unchanged: `skills/triage/SKILL.md` is `/tminus:triage`. PLAN rule 10: trust current docs. |
| 2 | 2026-11-22 | Scripts are called as `${CLAUDE_PLUGIN_ROOT}/scripts/tm <script> ...`; `tm` is a bash wrapper that picks the plugin venv Python if present, else `python3`. | `${CLAUDE_PLUGIN_ROOT}` is substituted inline in skill Markdown but is not exported to Bash-tool commands; a wrapper keeps venv selection in one place. |
| 3 | 2026-11-22 | Plugin venv default `~/.cache/tminus/venv`, override with `TMINUS_VENV`. | As in PLAN 5.0. `${CLAUDE_PLUGIN_DATA}` was considered but is not available to plain Bash calls. |
| 4 | 2026-11-22 | pymupdf pinned to 2.1 (current, tested) rather than 1.x. | It is the version installed and tested in the build venv. |
| 5 | 2026-11-22 | Install hints verified 2026-11-22 against package indexes: Arch (`pacman -Si`/`-Qo` on the build machine, all names); Debian stable/trixie (packages.debian.org contents search, all .sty mappings, latexmk, poppler-utils, python3-venv, python3-pip; tectonic not packaged); Homebrew (formulae.brew.sh: `tectonic`, `poppler`, casks `basictex`, `mactex-no-gui`; no brew latexmk, use `tlmgr install latexmk`); tlmgr names from ctan.org (tikz=pgf, bm/multicol/tabularx=tools, graphicx=graphics, amssymb=amsfonts, lmodern=lm). Fedora: `latexmk`, `poppler-utils`, `python3`, `texlive-tcolorbox` verified; tectonic not packaged. | PLAN 5.0 item 4. |
| 6 | 2026-11-22 | **UNVERIFIED** install hints: Ubuntu .sty mappings (assumed same as Debian; packages.ubuntu.com contents search failed); Fedora `texlive-<tlmgr name>` for packages other than tcolorbox, and `texlive-scheme-basic` / `texlive-collection-*` names; Fedora `tex(<file>.sty)` provides (not confirmed, so not used). | Could not be checked from the package indexes. |
| 7 | 2026-11-22 | Preflight scans `templates/*.tex` **and** `templates/*.sty` (`\usepackage` and `\RequirePackage`), since the shared style lives in `templates/tminus.sty`; `tminus` itself is excluded as a local package. `genanki` dropped from the optional list because Anki export is cut. | Templates load packages through one .sty, so the hardening is in one place. |
